# How to customize the ribbon items within the WinForms RibbonControlAdv in simplified layout?

This repository contains a sample that demonstrates how to customize ribbon items within the WinForms [RibbonControlAdv](https://help.syncfusion.com/windowsforms/ribbon/getting-started) in [simplified layout](https://help.syncfusion.com/windowsforms/ribbon/simplifiedlayout). The sample enables simplified mode by setting `EnableSimplifiedLayoutMode` to `true` and `LayoutMode` to `Simplified`, so commands are shown in one line.

It also shows how to customize item visibility by using `SetDisplayMode`, populate drop-down items such as fonts and color pickers, apply the `Office2019Colorful` theme, and configure tab groups. These settings help organize commands for compact WinForms interfaces while keeping the ribbon easy to use.
